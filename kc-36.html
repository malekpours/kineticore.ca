KC-36 Thermocouple Logger

A real-time temperature acquisition and visualization unit with 36 K-type thermocouple inputs — built on National Instruments hardware, calibrated by Kineticore.

Overview

Research-Grade Temperature DAQ, Ready Out of the Box

The KC-36 acquires, plots and logs data from 36 K-type thermocouple inputs — two 16-channel NI-9213 modules plus one 4-channel NI-9211 — with all channels automatically calibrated before display or logging. Every value you see on screen and in your CSV is calibrated data, never raw.

  • Real-time multi-channel graphing with zoom, pan and export
  • CSV logging with per-channel thresholds and alarm highlighting
  • Calibrated accuracy: ±0.5 °C typical within 0–100 °C calibrated range
  • Quality modes: Speed, Balanced, Accuracy — with open-thermocouple detection
  • High-durability write mode protects data against power loss
  • View-Only mode for monitoring without file creation

Specifications

KC-36 at a Glance

Thermocouple inputs36 × K-type (miniature & standard plugs)
Acquisition modules2 × NI-9213 (16 ch each) + 1 × NI-9211 (4 ch) in a cDAQ-9174 chassis
Calibrated accuracy±0.5 °C typical (0–100 °C calibrated range); ±2.2 °C typical outside range
Logging intervalConfigurable, 0.5 s minimum recommended
Temperature unitsCelsius, Fahrenheit, Kelvin
Data outputCSV (timestamp + calibrated temperature per channel) + JSON comments file
Quality modesSpeed · Balanced (default) · Accuracy — open-thermocouple detection in Accuracy mode
Data protectionStandard or High-Durability write mode (frequent flush + fsync)
Channel setupCustom channel names, layout columns, font size, per-channel high/low thresholds
SoftwareKineticore Thermocouple Logger v1.6.1 for Windows 10/11 (64-bit)
ConnectivityUSB to PC · 110 V AC power
Calibration serviceAnnual recalibration by Kineticore (checksum-protected calibration file)
